# Student Performance Analysis 📊

## Maincrafts Technology Internship – Task 1

This project focuses on analyzing student performance data using Python and visualization libraries to identify important academic performance patterns and insights.

## 📌 Objective

The objective of this project is to:
- perform data cleaning
- analyze student performance data
- visualize important trends
- identify relationships between academic factors

## 🛠 Tools & Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## 📂 Dataset Used

- Student Performance Dataset (`student-mat.csv`)

## 📊 Analysis Performed

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Statistical Summary
- Correlation Analysis
- Student Performance Comparison
- Data Visualization

## 📈 Key Insights

- Students with higher study time generally performed better academically.
- Higher absences negatively affected final grades.
- Correlation analysis helped identify relationships among variables.
- Visualization improved understanding of academic performance trends.

## 📷 Visualizations Included

- Histogram
- Scatter Plot
- Bar Chart
- Correlation Heatmap


## 🚀 Project Outcome

This project successfully demonstrated the complete workflow of data analysis using Python, including:
- data preprocessing
- analysis
- visualization
- insight generation
